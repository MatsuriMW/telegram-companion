# 上手指南

从零到「发一句好累，它读着你的日记回你」，大约 15 分钟。前三步做完就有一个能用的收件箱，后面几步是陪伴的部分。

## 第一步：建一个自己的 Telegram 机器人

1. 在 Telegram 里搜 `@BotFather`，发 `/newbot`。
2. 按提示起一个显示名，再起一个以 `bot` 结尾的用户名。
3. BotFather 会回你一串 **token**，形如 `1234567890:AA……`。这串东西等于机器人的密码，别发给别人。

## 第二步：装插件，填 token，配对

1. 在 Obsidian 的「设置 → 第三方插件 → 浏览」里搜 Telegram Companion，安装并启用。
2. 打开插件设置。最上面是一张**上手清单**，做完一步勾一步，照着走就行。
3. **Bot token**：贴上第一步拿到的 token。清单第 1 步变成 `机器人已连接：@你的机器人` 就接上了。
4. **配对**：清单第 2 步会显示一个 6 位配对码。在 Telegram 里打开你的机器人，点 Start，把这个码发给它。它回「配对好了」，你的账号就进了白名单。只有白名单里的人发的消息才会被处理，别人给你的机器人发消息不会有任何反应。

配对码只在白名单空着的时候有效；猜错几次就作废，点「换一个码」再来。想手动加人，也可以直接在「白名单」里填 Telegram 用户名（不带 `@`）或数字 ID，多个用逗号隔开。

日记放在哪、叫什么名字，跟着 Obsidian 的「日记」核心插件（或 Periodic Notes）的设置走，这里不用另外配。所以先确认「日记」核心插件是开着的，并且已经设好了文件夹和日期格式。

## 第三步：发第一条消息

给机器人发一句「测试」。

- 消息下面出现 ❤️，说明收到了。
- 打开今天的日记，这句话已经在里面。

到这里收件箱就能用了。几个顺手的设置：

- **日界时间**：经常熬夜的话设成 `04:00` 之类，凌晨发的消息会记在前一天。
- **插到某个标题后面**：让消息插到日记里某个标题或某一行后面，而不是文末。
- **下载图片和文件**：打开后图片会存进库里，并嵌进日记。

## 第四步：选一个模型后端

陪伴的部分要调模型。设置页往下翻到「背后的模型」，三选一：

**A. Claude 命令行**（已经订阅 Claude 的人最省事）

1. 装好 [Claude Code](https://claude.com/claude-code)，在终端里跑一次 `claude` 并登录。
2. 设置里「用哪个后端」选「Claude 命令行」。路径默认是 `~/.local/bin/claude`；不确定的话在终端里跑 `which claude` 看一眼。
3. 模型可以留「默认」，也可以选 sonnet / opus / haiku。

**B. Anthropic API**

「用哪个后端」选「Anthropic API」，填 API key 和模型名。

**C. OpenAI 兼容接口**（DeepSeek、OpenAI、OpenRouter、本机 Ollama……）

1. 「用哪个后端」选「OpenAI 兼容接口」。
2. 接口地址可以从右边的下拉里选常用的，也可以自己填，填到 `/v1` 为止。
3. 填 key（本机的 Ollama 可以空着）和模型名，模型名照那家服务的文档写。

填完点 **「发一句测试」**。弹出「模型回了：收到」就通了；弹出「没连上」的话，后面跟着的那句就是原因，常见的见文末。

## 第五步：写陪伴档案

1. 设置里「陪伴档案笔记」填一个路径（默认 `陪伴档案.md`），点右边的 **「新建模板」**。
2. 打开这页笔记。开头的「基本信息」（称呼、性别、年龄、教育程度、MBTI、职业、最近在关心什么）都是选填的，不想说的空着就行；下面几节把括号里的提示换成你自己的情况。不用一次写全，最值得先写的是「回我的时候」那一节：你希望被怎样回应、最烦哪种话。
3. 写得越具体，它回得越像懂你的人。能引用自己日记里的原话最好。

不写档案也能聊，它会按一套默认的方式回（先接住情绪、用日记里的事实回应、不说教）。

## 第六步：聊一聊

在 Telegram 里试这几句：

| 发 | 应该看到 |
|---|---|
| `你好` | 马上回一句招呼，带上你今天在做的事（这是默认的口癖，想换成自己的说法见下一步） |
| `对话模式` | 「💬 进入对话模式」 |
| 随便聊几句，比如「我这周都在忙啥」 | 先出现「💭 收到，在想……」，十几秒后换成正式回复，里面提到的事来自你这一周的日记 |
| `记 明天买牛奶` | 这一句照常记进日记 |
| `退出` | 「📝 回到记录模式」 |
| `小结` | 今天做成了什么、明天先做哪件 |
| `模型` | 现在用的模型，下面带切换按钮 |

对话里说得够多的话，退出后过一会儿它会再发一条「🧩 刚才聊的，我记了一下」，告诉你它往档案的「近况」里记了什么。记错了直接改那页笔记。

## 第七步（可选）：教它你的口癖

设置里有一节「口癖」。你平时怎么打招呼、开心了爱说什么，加进去：填触发词，选回法（打招呼 / 跟着说 / 回我写的话）。比如加一条触发词「呱」、回法「跟着说」、打开「开心」，以后你发「呱呱」它就回「呱呱呱！」。

## 第八步（可选）：给它换个人设

默认它是一个爱你、关心你、带着母亲般温柔的角色。想让它扮演别的角色（角色扮演、语 C 都行）：

1. 设置里打开「让它扮演一个角色」，点「人设笔记」右边的「新建模板」。
2. 在那篇笔记里写清楚角色是谁、怎么说话、怎么称呼你、回复用什么格式。
3. 想要好几个角色，把「人设笔记」填成一个文件夹，每篇笔记一个角色；在 Telegram 里发「人设」点按钮切换。

## 第九步（可选）：让它主动找你

- 每周日晚上它会重写一次「近况」并发给你；时间在设置的「陪伴档案怎么更新」里改。
- 想让它参考周报、项目复盘之类的笔记，把路径填进「每周更新时额外参考的笔记」，一行一个；填文件夹的话取文件名排最后的那一篇。
- 想要定时的日程推送、拖延任务提醒，可以另外装同一个作者的「螺旋日程」和「任务提醒」，它们会把消息发到同一个机器人。

## 常见问题

**发了消息没反应**
Obsidian 要开着，电脑不能在睡觉。再看设置页右上角是不是 `✅ 已连接`；不是的话检查 token；再看上手清单第 2 步是不是已经配对了。

**手机上的 Obsidian 里看不到这个插件**
这个插件只在桌面端运行，手机上不会加载。手机上不需要它：你在 Telegram 里发消息，电脑上的 Obsidian 收到后记进日记，再同步到手机。

**「没连上：Not logged in」或 403**
命令行后端用的是 `claude` 自己的登录。在终端里跑 `claude auth logout`，再 `claude auth login`。

**「没连上：模型接口 401 / 404」**
401 是 key 不对；404 多半是接口地址多写或少写了一段（应该到 `/v1` 为止），或者模型名拼错了。

**它老提同一件事**
它会避开最近一天自己说过的话；如果日记里这几天确实只有那一件事，可聊的就少。多记几笔，或者在陪伴档案的「回我的时候」里直接写「别老提 XX」。

**不想让它记我说过的话**
设置里关掉「参考对话模式里你说过的话」。已经攒下的会在下次每周更新后清空；也可以直接删掉插件 `data.json` 里的 `chatMemory`。

**想换个语言回我**
设置里「回复用的语言」填 English、日本語之类。机器人的固定提示语（「收到，在想……」这些）目前只有中文。
